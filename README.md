# Auto Browser Agent

AI-агент автономно управляет видимым браузером через Playwright MCP. Он сам выбирает инструменты, переходит между страницами, анализирует состояние сайта и выполняет многошаговые задачи.

Агент умеет:

- работать с persistent browser session, где пользователь уже авторизован;
- хранить важные факты текущей задачи;
- запрашивать подробные описания tools только при необходимости;
- проверять действия через security layer;
- продолжать работу после уточнения от пользователя.

## Установка и запуск

```bash
uv sync
copy .env.example .env
uv run python src/main.py
```

В `.env` укажите:

```env
OPENAI_API_KEY=...
OPENAI_BASE_URL=...
OPENAI_MODEL=gpt-6-luna
PLAYWRIGHT_MCP_TOKEN=...
```

После запуска агент подключается к Playwright MCP и открывает управляемый браузер. Задача задаётся в консоли в пригласительном поле ввода. Если для продолжения потребуется информация, агент задаст вопрос прямо в терминале.

## Используемые инструменты

- **Python 3.12+ и uv** — код приложения, установка зависимостей и запуск.
- **Playwright MCP** — управление браузером: переходы, поиск элементов, клики, ввод и снимки страницы. Сервер запускается через `npx`, поэтому нужен Node.js. Режим `--extension` подключает его к браузеру через расширение и токен `PLAYWRIGHT_MCP_TOKEN`.
- **OpenAI SDK (Responses API)** — выбор действий агентом через function calling. Отдельный вызов модели проверяет действия в security layer.
- **Собственные tools** — память фактов (`task_remember_fact`), получение полных схем (`tools_get_description`), завершение задачи и запрос ответа пользователя. `ToolOrchestrator` объединяет их с инструментами браузера.
